# Внесення змін

Усі зміни цього проєкту потрібно фіксувати в Git і відправляти до:

`https://github.com/JulianME28/Recheck_mord`

Основна гілка — `main`. Канонічний файл скрипта — `Code.gs`.

## Перед зміною

1. Виконайте `git pull --ff-only origin main`.
2. Переконайтеся, що робоча копія не містить чужих незавершених змін.
3. Збережіть копію чинного коду Apps Script, якщо зміна одночасно розгортається в Google Sheets.

## Після зміни

1. Перевірте синтаксис `Code.gs`.
2. Виконайте `git diff --check`.
3. Перегляньте `git diff` і переконайтеся, що в коміт не потрапили секрети, токени чи зайві локальні файли.
4. За зміни поведінки оновіть `README.md`, `docs/USER_GUIDE.md` і `docs/TECHNICAL_GUIDE.md`.
5. Створіть змістовний коміт.
6. Виконайте `git push origin main`.
7. Перевірте, що локальний `HEAD` збігається з `origin/main`.

Коміти цього репозиторію налаштовано створювати з email `vip.makhno@gmail.com`.

## Правила для коду

- Не перейменовуйте `Code.gs`.
- Не перейменовуйте публічні функції `WR_setupWarrantyAutomation_v1`, `WR_runDailyTransfer_v1` і `WR_installedOnEdit_v1` без окремої міграції тригерів.
- Не додавайте другу копію тих самих функцій у Apps Script.
- Не змішуйте функції `work-checker` із відповідальністю цього скрипта без окремого узгодженого дизайну.
- Не називайте локальну статичну перевірку доказом роботи в Google Sheets. Зміни, що впливають на таблиці, потрібно перевіряти на тестовій копії.
- Не запускайте `WR_runDailyTransfer_v1` на робочій таблиці для «перевірки синтаксису»: функція одразу змінює всі придатні рядки.

`archive/local-snapshots` містить вихідні локальні `.txt`-знімки. Вони збережені лише для історії та не є актуальним джерелом коду.
